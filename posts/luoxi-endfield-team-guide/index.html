洛茜配队：先把破防和附着喂满

洛茜的伤害不是“纯物理”也不是“纯灼热”。战技和连携第二段打物理，狼之珀、天赋沸血和终结技打灼热。真正决定队伍上限的，是能不能稳定给她 破防 + 法术附着，以及能不能在连携后的 15 秒暴击窗口里把终结技打进去。

先记住四件事

  1. 破防：击飞、倒地可以叠层，最多 4 层；猛击、碎甲会清空。洛茜战技想召出狼之珀，目标必须“已经破防”。
  2. 法术附着：灼热 / 电磁 / 寒冷 / 自然，最多 4 层；非灼热 + 灼热 = 燃烧。燃烧让洛茜天赋沸血 ×1.5。
  3. 连携是开关：敌人同时有破防 + 法术附着时触发；第二段消耗全部附着，按层数加伤害（每层 180%），并给 15 秒 +25% 暴击 / +50% 暴伤。
  4. 终结技要进窗口：在连携后开，吃满暴击 buff；它挂灼热附着，继续维持燃烧。

三套首选

队伍 一句话 什么时候用
洛茜 + 祀 + 洁尔佩塔 + 卡缪 综合最稳：祀给寒冷/笔意，卡缪给灼热/灼热脆弱，洁尔佩塔自然附着 + 法术脆弱 + 充能 大多数关卡；有卡缪就优先这队
洛茜 + 祀 + 洁尔佩塔 + 莱万汀 上限最高：莱万汀 15 秒终结技 + 洛茜暴击窗口 打木桩、能控轴、愿意给莱万汀 300 能量
洛茜 + 祀 + 洁尔佩塔 + 余烬 最稳高难：余烬倒地破防 + 全队护盾 开荒、高难、怕死

祀是这三队的共同核心：36% 灼热增幅、笔意记录 13%、连携按 4 层附着打 1150%，还能让 01 号位洛茜的连携冷却 -20 秒。

其他优势队

队伍 定位 核心逻辑
洛茜 + 洁尔佩塔 + 卡缪 + 余烬 无祀燃烧 卡缪热 + 洁尔佩塔自然 = 燃烧；余烬破防/盾
洛茜 + 洁尔佩塔 + 狼卫 + 余烬 低配燃烧 5★ 狼卫热/燃烧；余烬破防/盾
洛茜 + 管理员 + 洁尔佩塔 + 余烬/骏卫 物理特化 管理员结晶 +20% 物理；洁尔佩塔自然/法术脆弱
洛茜 + 管理员 + 黎风 + 骏卫 物理爆发 多破防 + 物理易伤；注意破防被清空
洛茜 + 别礼 + 祀 + 洁尔佩塔 冻结混伤 别礼寒冷爆发 + 祀寒冷增幅 + 洁尔佩塔法术脆弱
洛茜 + 诀 + 祀 + 洁尔佩塔 高抗特化 诀腐蚀全抗下降 + 囹圄控制
洛茜 + 狼卫 + 陈千语 + 昼雪 低配综合 燃烧 + 击飞破防 + 盾/冻结
洛茜 + 莱万汀 + 狼卫 + 洁尔佩塔 双 C 火 火系爆发；无盾/破防，吃能量

一套通用手法

  1. 先上附着：洁尔佩塔战技（自然 + 聚怪）或祀战技（寒冷/灼热 + 笔意）。
  2. 再给破防：余烬战技（倒地）、陈千语战技（击飞）或管理员战技（猛击）。
  3. 洛茜战技：命中已破防目标 → 狼之珀 → 爪印斫痕。
  4. 洛茜连携：确认 4 层附着后按第二段 → 消耗附着、拿暴击窗口、触发祀/卡缪/管理员连携。
  5. 洛茜终结技：在暴击窗口内开，挂灼热附着；有祀先开祀终结技吃 36% 灼热增幅。
  6. 收尾：管理员/骏卫/大潘/弭弗再消耗破防；然后补附着，进入下一轮。

替换原则

  • 没有祀：洁尔佩塔 + 卡缪/狼卫 + 余烬，靠自然 + 灼热打燃烧。
  • 没有洁尔佩塔：整体下降一档；用狼卫/卡缪 + 余烬 + 管理员/陈千语补破防和燃烧。
  • 怕死：优先保留余烬/昼雪，把最低收益的副 C 换成盾/奶。
  • 高抗性：上诀，靠腐蚀；高物抗：上伊冯/别礼/汤汤；高灼热抗：上管理员/黎风/骏卫。

数据与来源

  • 数据版本：2026-10-23，游戏 1.6；倍率为 M3 / Lv.9。
  • 来源：BWIKI 终末地 WIKI、CEP 终末地规划器、Skland 终末地 WIKI。
